# エターナル・レルム (Eternal Realm)

妖拳譚とは独立した、3DファンタジーRPGの開発リポジトリです。

## 公開・起動
GitHub Pages を有効にすると、次のURLでプレイできます。

https://ranchu534.github.io/eternal-realm/

## 現在の試作内容
- Three.js による3D草原フィールド
- キャラクター作成（名前・髪色・鎧色・外見タイプ）
- 三人称カメラ
- PC操作：WASD移動、Spaceジャンプ、J攻撃、マウスドラッグで視点変更
- スマートフォン操作：画面左の仮想スティック、ジャンプ・剣ボタン

## 開発メモ
現在は第1試作です。敵、攻撃判定、魔法、装備、クエスト、セーブ機能、広大なオープンワールドは今後追加します。
Three.js は jsDelivr CDN から読み込むため、プレイ時はインターネット接続が必要です。
